# 不背英语 (Bubei English) - 沉浸式学术英语背词 Web App

一款专为学术英语与深度记忆设计的现代沉浸式背单词 PWA 应用。内置近 6,000 个核心学术高频词汇，采用艾宾浩斯间隔重复算法（SRS）、肌肉记忆拼写测试、四选一极速自测及全套键盘快捷键支持。

## ✨ 核心特性

- 🧠 **科学 SRS 间隔重复系统**：动态排期算法（0天 → 1天 → 3天 → 7天 → 15天 → 30天），每日智能筛选到期复习词汇，新词限额引入，告别词库积压。
- 📚 **权威学术词库**：精编收录近 6,000 个考研/雅思/托福学术核心高频词汇（含词性、标准释义、双语经典例句与分级标签）。
- ✍️ **肌肉记忆拼写自测**：首轮听音拼写 + 错误词题自动进入“重练强化轮”，直至彻底内化。
- ⚡ **四选一极速自测**：支持“看英选义”与“听音辨词”，$O(1)$ 高性能动态混淆干扰项生成，带倒计时与反应速度加权计分。
- ⌨️ **全套桌面键盘快捷键**：
  - `Space`：翻转卡片 / 播放发音
  - `←` 或 `1`：标记为“模糊 / 重新学”
  - `→` 或 `2`：标记为“已掌握”
  - `R`：重播当前单词发音
  - `N`：呼出添加自定义生词弹窗
  - *输入框处于焦点时自动防误触保护*
- 📱 **移动端流畅触控交互**：支持卡片随指拖拽倾斜滑动，左滑标记“模糊”，右滑标记“掌握”，震动微触感反馈（Haptic Vibration）。
- 📝 **造句与记忆笔记**：支持对任意单词随手记录专属造句与联想记忆，自动持久化存储并在词库和卡片背面清晰展示。
- 📊 **学习统计与里程碑成就**：连续打卡天数（Streak）、掌握进度百分比、近 7 天背词柱状图，内置 8 大学术里程碑成就徽章。
- 📲 **PWA 离线秒开**：提供标准 `manifest.json` 与 Service Worker，支持“添加到手机主屏幕”原生全屏沉浸体验与断网离线背词。

## 🚀 部署上线指南 (GitHub Pages)

无需购买服务器，可以直接使用 GitHub 免费提供的 **GitHub Pages** 一键部署为公开网址：

1. 将本项目所有文件推送到 GitHub 仓库（例如 `bubei-english`）。
2. 在 GitHub 仓库页面上方点击 **Settings**（设置）。
3. 在左侧侧边栏找到 **Pages** 选项。
4. 在 **Build and deployment** 下的 **Branch** 下拉框中选择 `main`（或 `master`），目录选择 `/ (root)`，点击 **Save**。
5. 等待 1~2 分钟，刷新页面即可获得你的专属在线访问链接（形如 `https://your-username.github.io/bubei-english/`）。
6. 在手机浏览器（Safari / Chrome）中打开该网址，点击“添加到主屏幕”，即可作为独立 App 离线使用！
